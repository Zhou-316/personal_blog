# 文章评论区

日期：2026-10-24。本地实现，生产发布需同时更新前端和后端。

- 文章侧边的“回声”改为全文下方的评论区，文章与评论区默认居中。AI 总结从赞／评论右侧的入口按需展开；展开时显示在右侧，收起时恢复居中，生成过程中也可取消请求并收起。窄屏下总结显示在正文与评论区之间。
- 评论与回复均可点赞、取消点赞、继续回复。所有后续回复集中在所属主评论下方，并显示回复对象。
- 主评论与同一讨论下的回复分别按 `赞数 + 全部后续回复数 × 2` 降序排列；热度相同时按发布时间升序，时间相同再按 ID 升序。删除的评论不计入回复数或文章评论总数。
- 发送时间放在评论正文下方，使用 11px 灰色文字。发送失败时保留草稿，访客可以阅读讨论，登录后参与。
- 删除已有回复的评论时清除原文并显示“该评论已删除”，保留已有回复；可以继续回复其中未删除的评论。
- 播放器已移除“点击播放 · 网易云音乐”，保留播放控件及网易云账号入口。

## 数据与接口

后端启动时，`ensure_schema` 自动向 `comments` 增加可空的 `parent_id`、`root_id`、`deleted_at` 及回复索引。旧评论内容不变，作为主评论展示；迁移可以重复执行。

`POST /api/posts/{post_id}/comments` 接收 `content` 和可选的 `parent_id`。父评论必须属于当前文章且未删除。评论响应新增 `parent_id`、`root_id`、`reply_count`、`is_deleted`。`reply_count` 包含所有未删除的后续回复。删除接口额外返回 `retained`，表示是否保留用于连接已有回复的空评论。

回复会通知文章作者及被回复评论的作者，同一接收人只通知一次，不通知回复者自己。发布时需重启后端完成迁移，再使用新版前端。

## 验证

新增的 9 项后端集成测试位于 `backend/tests/test_threaded_comments.py`，覆盖多级回复、两种排序条件、通知、删除、权限、文章删除级联和旧评论迁移。连同原有 24 项媒体测试，33 项均通过。

本地 Edge 检查通过：发表评论、回复及再次回复、点赞重排、同分时间排序、失败保留草稿、刷新后持久化、删除评论后继续讨论、访客登录入口；1440/1024/768/390/360/320px 均无页面横向溢出。浏览器检查记录和截图保存在忽略目录 `.dist/local-acceptance/`，临时验收文章已清理。
