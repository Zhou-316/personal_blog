## 本轮结果

两种模式现在同时控制导航、首页大面板、文章与分类卡片、侧栏、个人中心、消息面板、音乐播放器和弹窗的材质。液态模式保留背景层次、反射边缘和局部指针高光；简化模式采用较厚的磨砂底色，并卸载复杂折射层。

导航和首页「写札记」按钮使用真实的背景边缘位移。折射装饰与原生按钮、输入框、文字分离；正文、编辑区、预览和评论区保留稳定的阅读底板。个人中心与移动端编辑标签只移动选中指示层，操作目标保持原位。

已删除的统计卡片、「最新一篇」和顶部「写札记」没有重新加入。GitHub 入口仍在个人中心左侧。

## 最终默认参数 B

| 参数 | B 默认值 | 使用位置与取舍 |
| --- | --- | --- |
| 导航底色透明度 | 0.20 | 简化模式为 0.90，液态模式能直接看到背景层次 |
| 背景模糊 | 8px | 导航与普通材质面板；首页大面板为其 0.4 倍 |
| 边缘位移强度 | 64 | SVG 滤镜参数，不等于均匀移动 64px |
| 折射边缘宽度 | 导航 9px、按钮 5px | 中央不施加位移 |
| 背景饱和度 | 135% | 导航与共享材质面板 |
| 色散 | 0.8 | 使用轻微分色，不对内容文字施加滤镜 |
| 卡片外层透明度 | 0.34 | 留出可见的背景与边缘 |
| 卡片读字衬底透明度 | 0.68 | 与外层叠加的中心有效不透明度约 0.79，边缘保留通透感 |
| 正文等阅读底板 | 0.96 | 与卡片参数独立，保障长文与输入清楚 |
| 指针高光半径 | 160px | 每帧最多更新两个实际悬停宿主 |
| 按压弹性参数 | 0.05 | 映射为最多 1.5% 的按钮缩放；文字与点击区域不跟随鼠标变形 |

参数集中在 `frontend/src/lib/glassPresets.ts`。材质样式集中在 `frontend/src/styles/materials.css`，以避免覆盖工作区中同时进行的阅读、评论与配乐布局调整。

## 调参过程与选择依据

第一轮比较 A/B/C 三套参数；随后围绕 B 单独比较导航透明度 0.15/0.20/0.25、模糊 6/8/10px、位移 56/64/72、色散 0.5/0.8/1.0、卡片外层透明度 0.28/0.34/0.40。每次改变一个参数，其余保持 B。

| 候选 | 截图观察 | 处理 |
| --- | --- | --- |
| A：较厚底色、较弱位移 | 更接近磨砂，卡片与背景的联系较弱 | 保留作轻档对照 |
| B：中间参数 | 卡片边缘与背景层次清楚，正文底色稳定 | 作为当前默认 |
| C：更透明、更强位移 | 背景存在感更强，材质表现更突出 | 保留作强档对照 |

单项比较没有发现足以推翻 B 整体取舍的问题，因此保留 B 的原始中间值。以上是实现者的截图与操作观察，没有开展读者盲测，不能证明所有设备与读者都会偏好 B。

开发环境可访问 <http://127.0.0.1:5175/?glassLab=1>，直接比较 A/B/C、简化模式和单项参数。预设与滑块仅用于本次打开的页面，刷新回到 B；用户选择的液态/简化模式会持久保存。调参面板及其专用 CSS 不进入生产构建。

## 性能与证据

复杂折射通常同时存在两个实例：首页导航与独立操作按钮；其他面板使用 CSS 材质。指针采用事件驱动的单次 `requestAnimationFrame` 合并，空闲时没有持续动画循环。滤镜范围收紧为宿主的 100%，不计算已被外壳裁掉的扩展区域。

测试路径：1440×1000 视口，固定模拟内容，连续往返滚动并向导航派发指针事件，每次 180 帧。自动 Chromium 报告 SwiftShader 软件渲染，两种模式均明显较慢；该结果保留在日志中。另用本机 Edge 的 RTX 5060 Laptop GPU / Direct3D11 路径复测，分别记录简化与液态模式，不将软件渲染结果冒充硬件帧率。

最终三轮复测如下，原始数值见 `.dist/liquid-glass-v2/final-checks-report.json`：

| 模式 | 三轮 p50 | 三轮 p95 | 超过 33.4ms 的帧占比 |
| --- | --- | --- | --- |
| 简化 | 16.7 / 16.6 / 16.7ms | 16.9 / 16.9 / 16.9ms | 0 / 0 / 0% |
| 液态 | 16.7 / 16.7 / 16.7ms | 33.5 / 33.4 / 16.9ms | 14.53 / 4.47 / 0% |

两种模式的中位帧间隔都约 16.7ms，但液态模式在重复压力测试中仍有波动，尚未稳定达到方案中 p95 约 20ms、超过 33.4ms 的帧不超过约 5% 的初始预算。不能只用此前单轮 p95 16.9ms 的较好结果宣称性能达标。本地验收应特别关注模式切换和滚动的实际感受；该自动化结果也不能代表其他硬件。

静置 1.2 秒期间新增的应用 `requestAnimationFrame` 请求为 0。最终生产产物检查和 Edge 检查均无脚本异常与资源错误。

## 用户本地验收

先在正常地址查看首页、卡片、阅读、个人中心与弹窗；将鼠标沿导航或卡片边缘移动，再切换简化模式比较。重点判断边缘是否清楚、卡片是否过亮或过灰、长文是否舒适、滚动是否顺畅。若 B 的强度仍不合适，可在开发面板比较 A/C，再按具体区域微调。
