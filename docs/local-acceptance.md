## 启动与停止

在项目根目录的 PowerShell 中执行：

```powershell
.\start-local-acceptance.ps1
```

脚本检查端口、准备示例数据，并在隐藏窗口的后台进程中启动服务。需要停止时执行：

```powershell
.\start-local-acceptance.ps1 -Stop
```

停止脚本按记录的进程 ID 与启动时间核对身份，只停止本次验收服务，保留数据。重新启动不会覆盖已创建的文章，也不会重置用户修改。

更换端口：

```powershell
.\start-local-acceptance.ps1 -FrontendPort 5175 -BackendPort 8002
```

启动前先停止上一组验收服务。端口被占用时脚本报错，不终止其他服务。

首次在新环境运行时，先安装依赖：

```powershell
npm --prefix frontend ci
npm --prefix music-service ci --ignore-scripts
python -m pip install -r backend/requirements.txt --target .dist/local-acceptance/python_packages
```

本轮图片与文章配乐验收使用 `.\start-local-acceptance.ps1 -WithMusic`，同时启动仅监听回环地址的网易云服务。详细操作及生产配置见 [图片与文章配乐更新](editor-media-update.md)。

本机原有 backend/.python_packages 与当前 Python 版本不匹配，因此验收启动脚本使用独立依赖目录。更换 Python 版本后，需要为新版本重新准备该目录。

需要检查生产构建时，先停止开发验收服务，再执行：

```powershell
.\start-local-acceptance.ps1 -Mode preview -FrontendPort 4174
```

该命令先构建，再在 4174 启动构建产物；API 仍代理到独立验收后端。

## 建议验收顺序

1. 未登录浏览首页，检查雪山背景、悬浮导航、首屏按钮、栏目与侧栏。桌面导航中的星光按钮可以切换完整和简化玻璃，并记住选择。
2. 登录站主账号，进入四个栏目和文章，检查长标题、正文、代码块、表格、图片、评论与点赞。
3. 写一篇测试札记，选择栏目，选择或拖拽上传图片，检查右侧预览，然后保存、编辑和删除。
4. 进入个人中心，查看评论通知、未读数字、个人信息和云朵私信；可用第二个账号在另一浏览器窗口验证双方消息。
5. 缩窄窗口，或在浏览器设备模拟模式中检查手机布局。触屏、小屏、减少动态效果和非 Chromium 浏览器默认采用简化玻璃。

服务仅监听本机回环地址，手机布局已在浏览器中模拟检查；同一 Wi-Fi 下的实体手机不能直接访问 127.0.0.1。如需实体手机验收，另行设置局域网访问地址与允许来源。
